PASSWORD MANAGERS

Lesson 1 explained why every account needs its own strong password, but nobody can memorise dozens of long, unique passwords on their own. A password manager solves that problem: it is an application that generates and stores a separate strong password for every site you use, locked behind one master password that only you know. You only have to remember that one master password; the manager fills in the rest for you.

HOW THEY WORK

When you create an account on a new site, the manager can generate a long, random password for it and save it in an encrypted vault. Encryption means the stored passwords are scrambled into unreadable data that can only be unlocked with your master password, so even if someone got hold of the vault file itself, they could not read what is inside without that key. Most managers can also fill the login form automatically, which is faster than typing and helps you avoid typing your password into a fake copy of a website by mistake.

WHY IT MATTERS

Using a manager removes the two mistakes from Lesson 1 at the same time: it makes reuse unnecessary, because generating a new password takes one click, and it removes the need to write passwords down anywhere insecure. The only password you still need to memorise - and choose carefully - is the master password itself, since it protects everything else.

CHOOSING A MANAGER

  • Look for one that encrypts your data before it leaves your device.
  • Pick a master password you have never used anywhere else.
  • Turn on two-factor authentication for the manager account (see Lesson 3).
  • Check that it works across the devices you actually use.
